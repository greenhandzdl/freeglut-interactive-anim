# OpenGL 人物演示 — 顶点动画 + 曲面细分

## 1. 项目概述

本项目是一个基于 FreeGLUT 和 OpenGL 4.1 实现的交互式人物演示程序。它展示了一个具有骨骼结构、顶点动画、曲面细分以及 Gooch 着色模型的 3D 人物模型。用户可以通过键盘和鼠标与场景进行交互，控制人物的行走、跳跃、挥手动画，调整光源亮度，以及改变曲面细分级别。

**主要技术栈：**
*   **FreeGLUT:** 窗口管理和事件处理库。
*   **OpenGL 4.1 (Core Profile):** 图形渲染 API。
*   **GLSL (OpenGL Shading Language):** 用于实现自定义着色器，包括顶点动画、曲面细分和光照模型。

## 2. 项目架构与模块划分

项目代码结构清晰，将不同的功能模块进行了有效分离：

*   `main.cpp`: 应用程序入口，负责 FreeGLUT 初始化、窗口创建、事件回调注册以及主渲染循环。
*   `math/`: 包含 `Vec3` (三维向量) 和 `Mat4` (四维矩阵) 等数学工具类，用于图形变换计算。
*   `geometry/`: 负责生成各种基础几何体网格数据，如圆柱、球体、台体以及特有的 SLERP 关节连接器。
*   `shaders/`: 存放 GLSL 着色器源码，包括顶点着色器、曲面细分控制着色器、曲面细分求值着色器和片段着色器。
*   `render/`: 封装了 OpenGL 的初始化、着色器编译链接、场景更新逻辑 (`updateAnimation`) 和每帧绘制逻辑 (`renderScene`)。

## 3. 核心功能与实现细节

### 3.1 人物模型生成

人物模型由多个基本几何体组合而成，并通过 `geometry` 模块中的函数生成。为了实现平滑的关节过渡，项目引入了 **SLERP 关节连接器**。

#### 伪代码：几何体生成

```markdown
// 圆柱/台体生成
FUNCTION genCylinder(centerX, centerY, centerZ, topRadius, bottomRadius, height, sides, rings, boneId, vertices, indices):
    baseIndex = vertices.size()
    FOR v FROM 0 TO rings:
        currentY = centerY + v * height
        currentRadius = topRadius * (1 - v) + bottomRadius * v
        FOR u FROM 0 TO sides:
            theta = u * 2 * PI / sides
            x = centerX + currentRadius * cos(theta)
            z = centerZ + currentRadius * sin(theta)
            Add Vertex(x, currentY, z, normal, uv, boneId) to vertices
        ENDFOR
    ENDFOR
    Generate triangle indices for cylinder/frustum surfaces
ENDFUNCTION

// UV 球体生成
FUNCTION genSphere(centerX, centerY, centerZ, radius, latitudes, longitudes, boneId, vertices, indices):
    baseIndex = vertices.size()
    FOR j FROM 0 TO latitudes:
        v = j / latitudes
        theta = v * PI
        y = centerY + radius * cos(theta)
        r = radius * sin(theta)
        FOR i FROM 0 TO longitudes:
            u = i / longitudes
            phi = u * 2 * PI
            x = centerX + r * cos(phi)
            z = centerZ + r * sin(phi)
            Calculate normal vector
            Add Vertex(x, y, z, normal, uv, boneId) to vertices
        ENDFOR
    ENDFOR
    Generate triangle indices for sphere surfaces
ENDFUNCTION

// SLERP 关节连接器生成
FUNCTION genJointConnector(def: JointConnectorDef, sides, rings, vertices, indices):
    parentEndX, parentEndY, parentEndZ = def.parentEnd
    jointX, jointY, jointZ = def.jointCenter
    startRadius = def.startRadius
    endRadius = def.endRadius
    boneId = def.parentBone

    // 计算连接器轴向 (从父骨骼末端指向关节中心)
    axisVector = (jointX - parentEndX, jointY - parentEndY, jointZ - parentEndZ)
    axisLength = length(axisVector)

    // 计算从父骨骼局部 Y 轴到连接器轴向的 SLERP 旋转轴和角度
    startDirection = (0, 1, 0)
    endDirection = normalize(axisVector)
    rotationAxis = cross(startDirection, endDirection)
    rotationAngle = acos(dot(startDirection, endDirection))

    // 沿连接器轴向分段生成环形顶点
    FOR r FROM 0 TO rings:
        t = r / rings // 插值因子
        currentRadius = lerp(startRadius, endRadius, t)
        currentCenter = lerp(parentEnd, jointCenter, t)

        // SLERP 插值计算当前环的旋转四元数
        currentRotation = slerp(identityQuaternion, quaternionFromAxisAngle(rotationAxis, rotationAngle), t)

        FOR s FROM 0 TO sides:
            angle = s * 2 * PI / sides
            // 在局部平面上生成顶点，然后应用 SLERP 旋转和平移
            localVertex = (currentRadius * cos(angle), 0, currentRadius * sin(angle))
            rotatedVertex = applyQuaternionRotation(localVertex, currentRotation)
            finalVertex = currentCenter + rotatedVertex
            Add Vertex(finalVertex.x, finalVertex.y, finalVertex.z, normal, uv, boneId) to vertices
        ENDFOR
    ENDFOR
    Generate triangle indices for connector surfaces
ENDFUNCTION
```

### 3.2 顶点动画系统

人物的行走、跳跃和挥手动画在 **顶点着色器 (Vertex Shader)** 中实现。通过传入 `uTime`、`uJumpPhase`、`uMoveSpeed`、`uWavePhase` 等 Uniform 变量，着色器根据骨骼 ID 对每个顶点进行局部变换。项目采用了一种动画层混合系统，确保不同动画（挥手、跳跃、行走）之间能平滑过渡或按优先级覆盖。

#### 伪代码：顶点着色器动画逻辑

```markdown
// Vertex Shader (VS_SOURCE)
#version 400 core

// 输入顶点属性
layout(location = 0) in vec3 inPos;
layout(location = 1) in vec3 inNormal;
layout(location = 3) in int  inBoneId;

// Uniform 变量
uniform float uTime;         // 全局时间
uniform float uJumpPhase;    // 跳跃阶段 (0.0 - 1.0)
uniform vec2  uMoveDir;      // 移动方向 (x, z)
uniform float uMoveSpeed;    // 移动速度
uniform float uWavePhase;    // 挥手阶段 (0.0 - 1.0)
uniform float uWaveWeight;   // 挥手动画权重 (0.0 - 1.0)
uniform float uCameraAngle;  // 摄像机角度，用于挥手方向

// 骨骼关节位置定义 (硬编码)
vec3 jointPos(int boneId) { ... }
int getBoneGroup(int boneId) { ... } // 获取骨骼所属组

// 旋转辅助函数
vec3 rotateX(vec3 p, float angle) { ... }
vec3 rotateY(vec3 p, float angle) { ... }
vec3 rotateZ(vec3 p, float angle) { ... }
vec3 rotateAroundAxis(vec3 p, vec3 axis, float angle) { ... }

void main() {
    vec3 pos = inPos;
    vec3 norm = inNormal;
    int bone = inBoneId;
    int group = getBoneGroup(bone);

    float walkFreq = 3.0; // 行走动画频率
    float t = uTime * walkFreq; // 动画时间
    float speedFactor = clamp(uMoveSpeed, 0.0, 1.0); // 速度因子

    // 计算行走动画参数
    float swingAmp = 1.0 * speedFactor; // 摆臂幅度
    float kneeBend = 0.7 * speedFactor; // 膝盖弯曲
    float elbowBend = 0.4 * speedFactor; // 手肘弯曲
    float bodyBob = 0.10 * speedFactor; // 身体上下浮动
    float bodySway = 0.05 * speedFactor; // 身体左右摇摆
    float hipTwist = 0.12 * speedFactor; // 臀部扭动

    // 计算跳跃动画参数
    float jumpH = 0.0; // 跳跃高度
    float jumpTuck = 0.0; // 身体收缩
    float jumpTwist = 0.0; // 身体扭转
    IF uJumpPhase > 0.0 AND uJumpPhase < 1.0 THEN
        phase = uJumpPhase * PI
        jumpH = 1.0 * sin(phase)
        jumpTuck = 0.6 * sin(phase)
        jumpTwist = 0.3 * sin(phase * 2.0)
    ENDIF

    // 根据骨骼ID应用变换
    IF bone == ROOT_BONE THEN
        pos.y += bodyBob * sin(t) + jumpH;
        pos.x += bodySway * cos(t);
    ELSE IF bone == HEAD_BONE THEN
        // 头部动画 (跟随身体摆动，略微点头)
        pos.y += bodyBob * sin(t) + jumpH;
        pos.x += bodySway * cos(t);
        Apply rotation around jointPos(HEAD_BONE) based on nod factor
    ELSE IF bone IS ARM_BONE THEN
        // 手臂动画 (行走、跳跃、挥手混合)
        isLeft = (bone == LEFT_ARM_SHOULDER || bone == LEFT_ARM_ELBOW)
        sign = isLeft ? 1.0 : -1.0

        // 行走层动画角度
        walkShoulderAngle = swingAmp * sign * sin(t)
        walkElbowAngle = elbowBend * sign * abs(sin(t))

        // 跳跃层动画角度
        jumpShoulderAngle = -jumpTuck * 0.3 * sign
        jumpElbowAngle = -jumpTuck * 0.4 * sign

        // 挥手层动画角度 (仅右臂)
        waveShoulderAngle = 0.0
        waveElbowAngle = 0.0
        IF NOT isLeft AND uWaveWeight > 0.0 THEN
            // 计算挥手方向和角度，使手臂朝向摄像机前方挥动
            // ... (根据 uCameraAngle 和 uWavePhase 计算)
            waveShoulderAngle = -1.2 // 向前举起
            waveElbowAngle = 0.8 * sin(uWavePhase * 8.0) // 小臂左右摆动
        ENDIF

        // 动画层混合 (优先级: 挥手 > 跳跃 > 行走)
        finalShoulderAngle = walkShoulderAngle + jumpShoulderAngle
        finalElbowAngle = walkElbowAngle + jumpElbowAngle
        IF NOT isLeft AND uWaveWeight > 0.0 THEN
            finalShoulderAngle = waveShoulderAngle
            finalElbowAngle = waveElbowAngle
        ENDIF

        // 应用肩部和肘部旋转
        // ... (根据骨骼层次结构和旋转角度变换顶点)
    ELSE IF bone IS LEG_BONE THEN
        // 腿部动画 (行走、跳跃)
        // ... (类似手臂动画逻辑，根据骨骼ID和动画参数应用旋转)
    ENDIF

    // 输出变换后的位置和法线
    vPos = pos;
    vNorm = norm;
    vBone = bone;
}
```

### 3.3 曲面细分 (Tessellation)

为了使人物模型表面更加光滑，项目利用 OpenGL 的曲面细分着色器阶段。通过 **PN 三角形 (PN Triangles)** 技术，在 GPU 上动态生成更密集的几何体，从而实现平滑的曲面效果。用户可以通过 `+/-` 键调整细分级别。

#### 伪代码：曲面细分着色器

```markdown
// Tessellation Control Shader (TCS_SOURCE)
#version 400 core
layout (vertices = 3) out;

in  vec3 vsPos[];
in  vec3 vsNorm[];
in  vec2 vsTex[];
flat in int vsBone[];

out vec3 tcPos[];
out vec3 tcNorm[];
out vec2 tcTex[];
flat out int tcBone[];

patch out vec3 p300, p030, p003; // Bezier 控制点
patch out vec3 p210, p120, p021, p012, p102, p201, p111; // Bezier 控制点

uniform float uTessLevel; // 细分级别

void main() {
    tcPos[gl_InvocationID] = vsPos[gl_InvocationID];
    tcNorm[gl_InvocationID] = vsNorm[gl_InvocationID];
    tcTex[gl_InvocationID] = vsTex[gl_InvocationID];
    tcBone[gl_InvocationID] = vsBone[gl_InvocationID];

    IF gl_InvocationID == 0 THEN
        // 计算 PN 三角形的 Bezier 控制点
        p300 = vsPos[0]; p030 = vsPos[1]; p003 = vsPos[2];
        // ... (根据顶点位置和法线计算其他 Bezier 控制点 p210, p120, ..., p111)

        // 设置细分级别
        tess = clamp(uTessLevel, 1.0, 12.0);
        gl_TessLevelInner[0] = tess;
        gl_TessLevelOuter[0] = tess;
        gl_TessLevelOuter[1] = tess;
        gl_TessLevelOuter[2] = tess;
    ENDIF
}

// Tessellation Evaluation Shader (TES_SOURCE)
#version 400 core
layout(triangles, fractional_even_spacing, ccw) in;

in  vec3 tcPos[];
in  vec3 tcNorm[];
in  vec2 tcTex[];
flat in int tcBone[];

patch in vec3 p300, p030, p003, p210, p120, p021, p012, p102, p201, p111;

out vec3 fPos;
out vec3 fNorm;
out vec2 fTex;
flat out int fBone;

uniform mat4 uMVP; // 模型视图投影矩阵
uniform mat4 uModel; // 模型矩阵

// Bezier 曲面求值函数
vec3 bezierPoint(float u, float v, float w) { ... }

void main() {
    // 获取细分坐标 (barycentric coordinates)
    float u = gl_TessCoord.x;
    float v = gl_TessCoord.y;
    float w = gl_TessCoord.z;

    // 在 Bezier 曲面上求值得到新的顶点位置
    vec3 pos = bezierPoint(u, v, w);

    // 插值法线和纹理坐标
    vec3 n_interp = tcNorm[0] * u + tcNorm[1] * v + tcNorm[2] * w;
    vec3 norm = normalize(n_interp);
    vec2 tex = tcTex[0] * u + tcTex[1] * v + tcTex[2] * w;

    // 变换到世界空间和裁剪空间
    fPos  = (uModel * vec4(pos, 1.0)).xyz;
    fNorm = normalize((uModel * vec4(norm, 0.0)).xyz);
    fTex  = tex;
    fBone = tcBone[0];
    gl_Position = uMVP * vec4(pos, 1.0);
}
```

### 3.4 光照与材质 (Gooch Shading)

场景中的光照采用 **Gooch 着色模型**，这是一种非真实感渲染技术，能够产生卡通或技术插画般的效果。它通过混合冷色调和暖色调来表示漫反射，并结合了高光、菲涅尔反射和边缘光效果。场景中包含一个绕人物轨道运动的点光源，其亮度和位置均可交互调整。

#### 伪代码：片段着色器光照逻辑

```markdown
// Fragment Shader (FS_SOURCE)
#version 400 core

in vec3 fPos;  // 世界空间顶点位置
in vec3 fNorm; // 世界空间顶点法线
flat in int fBone; // 骨骼ID

out vec4 fragColor;

// Uniform 变量
uniform vec3 uLightPos;    // 光源位置
uniform vec3 uLightColor;  // 光源颜色
uniform float uLightRadius; // 光源半径 (用于衰减)
uniform vec3 uAmbient;     // 环境光颜色
uniform vec3 uCoolColor;   // Gooch 冷色调
uniform vec3 uWarmColor;   // Gooch 暖色调
uniform vec3 uCamPos;      // 摄像机位置
uniform vec3 uColors[10];  // 骨骼颜色数组

void main() {
    vec3 N = normalize(fNorm); // 归一化法线

    // 计算光照向量 L 和衰减 atten
    vec3 L_orig = uLightPos - fPos;
    float dist = length(L_orig);
    vec3 L = normalize(L_orig);
    float atten = clamp(1.0 / (1.0 + (dist * dist) / (uLightRadius * uLightRadius)), 0.0, 1.0);

    // 计算视线向量 V
    vec3 V = normalize(uCamPos - fPos);

    // Gooch 漫反射
    float t = dot(N, L) * 0.5 + 0.5; // 将 N.L 映射到 [0, 1]
    vec3 goochColor = mix(uCoolColor, uWarmColor, t);

    // 高光 (Blinn-Phong 简化)
    vec3 H = normalize(L + V); // 半角向量
    float spec = pow(max(dot(N, H), 0.0), 64.0);
    vec3 specColor = uLightColor * spec * 0.8 * atten;

    // 菲涅尔反射 (近似)
    float fresnel = pow(1.0 - max(dot(N, V), 0.0), 3.0);
    vec3 fresnelColor = mix(vec3(0.04), uLightColor, fresnel * 0.5);

    // 边缘光 (Rim Lighting)
    float rim = 1.0 - max(dot(N, V), 0.0);
    vec3 rimColor = uLightColor * pow(rim, 2.0) * 0.3 * atten;

    // 骨骼颜色叠加 (根据 fBone 索引从 uColors 数组中获取)
    int idx = clamp(fBone, 0, 9);
    vec3 boneColor = uColors[idx];
    goochColor = mix(goochColor, boneColor, 0.2); // 将骨骼颜色与 Gooch 颜色混合

    // 最终颜色组合
    vec3 finalColor = goochColor * (uAmbient + 0.6 * atten)
                    + specColor
                    + fresnelColor * 0.5
                    + rimColor;

    // 透明度 (模拟玻璃质感)
    float alpha = 0.75 + 0.25 * (1.0 - abs(dot(N, V)));

    // Gamma 校正
    finalColor = pow(finalColor, vec3(1.0 / 2.2));

    fragColor = vec4(finalColor, alpha);
}
```

### 3.5 摄像机控制

摄像机实现了围绕人物的轨道运动，并支持缩放和高度调整。用户可以通过鼠标左键拖拽来旋转和升降摄像机，通过鼠标滚轮进行缩放，也可以使用方向键微调。

### 3.6 用户交互

程序通过 FreeGLUT 回调函数处理用户输入：

*   **键盘:**
    *   `W/A/S/D`: 控制人物移动 (相对于摄像机方向)。
    *   `SPACE`: 人物跳跃。
    *   `E`: 控制人物挥手动画 (右臂)。
    *   `[/]`: 降低/增加场景光源亮度。
    *   `+/-`: 增加/减少曲面细分级别。
    *   `ESC`: 退出程序。
*   **鼠标:**
    *   **左键拖拽:** 旋转和升降摄像机。
    *   **滚轮:** 缩放摄像机。
